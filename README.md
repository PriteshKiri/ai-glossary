# Primer

A static Next.js field guide to AI terms, A through Z. Definitions live in the repo. There is no database.

Each letter has at least five terms. Every term has a short definition, a practical note, and two links to primary learning material. The index has search plus filters for letter, topic, and level. Two short paths — Start here, and Use a model — order the terms worth reading first.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
